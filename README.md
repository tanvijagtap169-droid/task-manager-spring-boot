# Task Manager Web Application

A full stack web app built with Java and Spring Boot that lets users add, view, edit and delete tasks (CRUD).

## Tech Stack
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: Java, Spring Boot, Spring Web (REST API)
- Database: H2, Spring Data JPA

## Features
- Add tasks with title, description, due date and status
- Edit tasks and mark them as DONE
- Delete tasks
- Data saved permanently

## How to Run
1. Install Java 17 or higher
2. Clone this repository
3. Run: ./mvnw spring-boot:run
4. Open http://localhost:8080
